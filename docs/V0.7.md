# v0.7 — Creative + Funnel Engine Foundation

Adds a creative brief generator and conversion-funnel specification generator tied directly to each Growth Engine campaign.

Selected stack:
- Penpot: durable design system/prototyping.
- Polotno Studio: editable campaign graphics and agent-assisted design.
- Motion: lightweight production web animation.
- GSAP patterns: selective premium scroll/cinematic effects.
- Remotion: candidate for automated video variants after license review.
- Mautic patterns: segmentation/campaign concepts without immediately adding a second marketing database.

The production Rescu website remains separate. This commit does not alter Rescu.life or Resculife-ai.
