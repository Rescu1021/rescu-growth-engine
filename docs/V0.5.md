# v0.5 — Gmail Approval + Follow-up Control

## Flow
A-tier + verified public business email + not suppressed -> Gmail draft payload -> human review -> send.

## Guardrails
- Draft-first. No autonomous cold-email sending.
- Any reply stops the no-reply sequence.
- Opt-out, explicit disinterest, bad contact and hard bounce permanently suppress the address.
- Maximum two no-reply follow-ups.
- Suppression is checked before a draft is prepared.
- No patient data or sensitive health targeting.

## Connected Gmail operating model
ChatGPT can create Gmail drafts from approved queue items using the connected Gmail account. Sending remains a separate explicit action after review.

## Reply intelligence
Classify inbound replies into: positive_reply, question, partner_meeting, appointment, not_interested, opt_out, bad_contact. Feed these outcomes back into Growth Engine scoring.
