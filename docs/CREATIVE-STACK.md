# Rescu Creative + Funnel Stack

## Selected architecture

### 1. Graphic design system: Penpot + Polotno Studio
Use Penpot for the durable Rescu design system: tokens, components, layouts, landing-page prototypes and developer handoff.
Use Polotno Studio for fast editable campaign graphics and agent-assisted social/ad creative.

Rescu tokens:
- OX Plum #481B2E
- Tangerine #E7714D
- Lavender #BAA5C0
- Cerulean #DCDFE7
- Fawn #F9E3DB
- Chalk #F7F7F7

Never invent or substitute the Rescu logo. Use approved Rescu brand assets and real facility/founder photography.

### 2. Web animation: Motion
Use Motion for lightweight production web animation: hero entrances, card reveals, CTA emphasis, accordions, carousels and scroll-linked effects.
Default to progressive enhancement and prefers-reduced-motion. Do not make SEO-critical content dependent on JavaScript animation.

### 3. Cinematic landing-page references: GSAP patterns
Use GSAP/ScrollTrigger patterns selectively for premium campaign pages when the visual lift justifies the payload. Avoid heavy WebGL on core conversion pages unless measured performance supports it.

### 4. Programmatic video: Remotion candidate
Remotion is the mature candidate for automated campaign video variants. Do not make it a required production dependency until its commercial license requirements are reviewed/approved.

### 5. Funnel/marketing automation: Mautic patterns
Borrow Mautic's segmentation, campaign state, contact history and event concepts. Do not deploy a second marketing database by default. Rescu Growth Engine remains the source of truth until there is a clear need for a dedicated marketing automation server.

### 6. Funnel frontend
Keep Rescu.life crawlable, fast and server/static rendered. Landing pages must preserve:
- unique indexable URL
- title/meta/canonical
- real HTML offer copy
- fast LCP
- no SPA catch-all
- UTM capture
- campaign + lead-source attribution
- Google Meet / WhatsApp / booking CTAs

## Creative pipeline
Lead segment -> Offer -> Campaign brief -> Landing page -> Graphic variants -> Motion variants -> Email -> CTA -> Conversion event -> Revenue feedback.

## Campaign outputs
Each campaign should generate:
1. target-specific headline
2. offer stack
3. proof/credibility section
4. objection handling
5. $100 Rescu Credit language only for eligible non-clinical promotional partners
6. keyword reply CTA
7. 15-minute Google Meet CTA
8. booking/WhatsApp CTA when appropriate
9. square social creative brief
10. 9:16 story/reel creative brief
11. 16:9 display/video creative brief
