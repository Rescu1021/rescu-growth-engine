# Rescu Growth Engine

Private market-intelligence and lead-prioritization engine for Rescu Wellness.

## Purpose
Turn public/licensed business and provider data into prioritized partnership and referral opportunities for Rescu — without patient data or automatic spam blasting.

## Initial campaigns
- HBOT / athlete & sports referrals
- Ozone / physician & wellness referral partners
- Orthopedics / PT / rehab
- Gyms / CrossFit / trainers
- Pelvic-floor referral partners
- Aesthetics / plastics / dermatology
- Corporate wellness
- Golf / tennis / pickleball / sports clubs
- Strategic local partnerships

## Geographic priority
1. Scarsdale + nearby Westchester
2. Westchester County (deprioritize White Plains clinician outreach)
3. Greenwich / Stamford / Fairfield County
4. Bronx / Queens / NYC
5. Broader tri-state

## Pipeline
collect -> normalize -> dedupe -> qualify -> score -> assign -> export

## Data policy
Public/licensed business and provider data only. No patient lists, protected health information, private health data, passwords, or automated mass outreach. Human review before outreach.

## Quick start
```bash
python -m rescu_growth.demo
```
